# Pocket Pier

Playable Phaser vertical slice for the portal fishing game concept.

## Run

```bash
npm install
npm run dev
```

Tap/click or use Space to cast. Underwater, hold and drag, use WASD, or use the arrow keys to steer. Press E/Space or use Reel In to return to the surface.

## Current scope

- Responsive desktop/mobile canvas
- Cast and directly controlled underwater hook exploration
- Limited line, two-slot basket, moving fish and a hidden treasure
- Three-dive Fishing Trips and summary rewards
- Six Sunny Pier fish as the balance slice
- Versioned local save and mock PortalBridge hooks
- Generated local assets, procedural underwater visuals and no external runtime requests

Next milestone: play-test the core feel, then add the full data-driven catalog, collection, quests, gear, bait and zones.
